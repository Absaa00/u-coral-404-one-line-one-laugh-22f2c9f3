# One Line, One Laugh

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3)

Entry for the [One Line, One Laugh bounty](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3) on make.fun.

`main.py` writes exactly one funny line — a joke, a quip, a punchy
observation, capped at 200 characters and nothing else — to
`/output/entry.txt`. The program is deterministic (no randomness, no
network, no clock): two runs produce a byte-identical file.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
